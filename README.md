# Viajes Virgo

Sitio web de **Viajes Virgo**, agencia de viajes en Monterrey, N.L., con más de 30 años de experiencia en viajes nacionales e internacionales.

🌐 **https://viajesvirgo.com**

## Qué incluye

Una sola página con secciones de **Playas, Ciudades, Cruceros y Parques**, y un formulario de contacto que envía las solicitudes por correo a la agencia.

## Tecnologías

HTML, CSS y JavaScript sin frameworks, y PHP para el formulario. Diseño adaptable a celular, tablet y computadora.

## Estructura

```
index.html      Página principal (todas las secciones)
mail.php        Envío del formulario de contacto
css/            Estilos (celular, tablet y laptop)
js/menu.js      Menú de hamburguesa
imagenes/       Logos y fotos de destinos
```

## Probarlo en tu computadora

```bash
git clone https://github.com/iecgerman/viajesvirgo.git
cd viajesvirgo
php -S localhost:8000
```

Abre http://localhost:8000. Para solo ver el diseño, basta con abrir `index.html`; el formulario necesita PHP y un servidor de correo para funcionar.
